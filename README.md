1. Organisation Overview
Organisation Name: ComServe (Non-Profit Organisation)
ComServe is a proposed non-profit community event and contribution platform designed to help local neighbourhoods organise, manage and participate in community activities. The platform provides residents with a central place to access community events, announcements, notifications and contribution information.
Many communities currently rely on messaging applications and social media to communicate. However, information can become difficult to organise and access when communication is spread across different platforms. Research indicates that digital information and communication technologies can help strengthen neighbourhood social connections and social cohesion
Each registered user will belong to a specific community and will only have access to events and notifications associated with that community.
Target audience:
•	Community residents
•	Community leaders and administrators
•	Event organisers
•	Volunteers
•	Neighbourhood associations
2. Website Goals and Objectives
The main goal of ComServe is to improve communication, participation and cooperation within local communities.
The website objectives are to:
•	Provide one central platform for community communication.
•	Allow residents to create and manage events.
•	Allow residents to contribute fixed amounts towards community activities.
•	Provide community-specific notifications.
•	Encourage participation in neighbourhood activities.
•	Give administrators tools to manage members and content.
Digital platforms can support communication between residents and organisations, particularly when they are designed to encourage participation and interaction (Khene et al., 2021).
Key performance indicators will include:
•	Number of registered residents.
•	Number of events created.
•	Number of event participants and RSVPs.
•	Number of contributions made.
•	Number of community announcements viewed.

3. Current Website Analysis
ComServe is a new proposed platform and therefore does not currently have an existing website to analyse. The concept is based on addressing common problems experienced when communities rely on separate messaging groups and social media platforms for communication.
Information can become difficult to locate, older announcements can become buried in conversations, and important information may not always reach the correct community members.
ComServe will address these issues by placing event information, contributions, notifications and community communication into one organised platform. This approach is supported by research into digital citizen engagement in South Africa, which demonstrates how digital platforms can support communication between communities and organisations (Chiumbu & Hlongwane, 2015).
4. Proposed Website Features and Functionality
The website will include:
1.	User Registration and Login – Accounts will be linked to a specific community.
2.	Home Page – Displays community announcements and featured events.
3.	Event Creation – Organisers can provide the event title, description, date, time, location, event type, contact details and contribution amount.
4.	Event Categories – Celebrations, Funerals, Community Projects, Meetings, and Emergency & Notices.
5.	Event Pages – Display event details, contribution progress, RSVP status and resident comments.
6.	Contributions – Events can have a fixed contribution amount, allowing residents to see the contribution requirement and fundraising progress.
7.	Notifications – Users receive information relevant to their own community.
8.	Administration – Administrators can manage members and approve or remove content.
9.	Contact Page – Allows residents to communicate with administrators.
The event features are intended to encourage residents to participate directly in community activities. Research into community engagement and events highlights the importance of involving host communities in event activities (Senevirathna, Jin & Wang, 2023).
5. Design and User Experience
ComServe will use a clean, friendly and simple design that makes community information easy to understand.
•	Colour Scheme: Blue, white and light neutral colours to create a trustworthy and welcoming appearance.
•	Typography: Aptos will be used for the main content, with larger and bold headings to create a clear hierarchy.
•	Layout: A card-based layout will be used for events and announcements, allowing users to quickly scan important information.
Navigation will be kept simple, with clear links to the Home, Events, Create Event, Notifications and Contact sections. The website will also be responsive so that it can be used on computers, tablets and smartphones.
A low-fidelity wireframe will be created to demonstrate the placement of the navigation, event cards, announcements, contribution information and other major content areas.
6. Technical Requirements
ComServe will be developed using HTML5 for the website structure, CSS for styling and responsive design, and JavaScript for interactive functionality.
The website will require a domain name and web hosting. Development will be completed using appropriate code-editing and web-development tools.
The initial version of the project will focus on the front-end website structure and functionality, with more advanced features potentially being implemented in later development stages.

8. Budget
The project will use free or low-cost development resources wherever possible. Most of the resources required for the project will be obtained through the GitHub Student Developer Pack, which provides students with access to various development tools, services and resources.
Using these student resources will significantly reduce the overall development cost. The estimated remaining cost of the project is approximately R500–R1,500, depending on resources required outside of the GitHub Student Developer Pack.
Development software and other educational resources will primarily be obtained through free student resources. As ComServe is a non-profit organisation, the project will focus on keeping operational and development costs as low as possible.
9. Conclusion
ComServe aims to strengthen communication and cooperation within neighbourhoods by bringing event management, contributions, notifications and community engagement together in one organised platform.
As a non-profit organisation, ComServe's primary purpose is to support communities rather than generate profit. The website will make it easier for residents to stay informed, participate in community activities and support local initiatives while giving administrators better tools to manage their communities.
