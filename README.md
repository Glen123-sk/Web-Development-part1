## 1. Organisation Overview
- **Organisation Name:** ComServe (Non-Profit Organisation)
- **Summary:** ComServe is a proposed non-profit community event and contribution platform designed to help local neighbourhoods organise, manage and participate in community activities. The platform provides residents with a central place to access community events, announcements, notifications and contribution information.
- **Problem:** Many communities rely on messaging apps and social media, which scatters information and makes it hard to organise and access important notices.
- **Access model:** Each registered user belongs to a specific community and sees only events and notifications for that community.
- **Target audience:** Community residents, leaders/administrators, event organisers, volunteers, and neighbourhood associations.

## 2. Website Goals and Objectives
The main goal is to improve communication, participation and cooperation in local communities. Objectives include:
- Provide a single platform for community communication.
- Allow residents to create and manage events.
- Support fixed-amount contributions for community activities.
- Deliver community-specific notifications.
- Encourage participation in neighbourhood activities.
- Provide administrative tools to manage members and content.

**Key performance indicators (KPIs):** number of registered residents, events created, event participants/RSVPs, contributions made, announcements viewed.

## 3. Current Website Analysis
ComServe is a new proposal and does not have an existing site. The platform addresses common issues with scattered communications (buried messages, missed announcements) by centralising events, contributions and notifications.

## 4. Proposed Features & Functionality
Core features:
1. User registration & login (accounts linked to communities)
2. Home page with community announcements and featured events
3. Event creation with title, description, date/time, location, type, contact, contribution amount
4. Event categories: Celebrations, Funerals, Community Projects, Meetings, Emergency & Notices
5. Event pages with contribution progress, RSVP status and comments
6. Contributions tracking and fundraising progress
7. Community-specific notifications
8. Administration tools for members and content moderation
9. Contact page for resident–administrator communication

## 5. Design & User Experience
- **Style:** Clean, friendly, simple. Colour scheme: blue, white, light neutrals.
- **Typography:** Aptos for main content; clear hierarchy with larger headings.
- **Layout:** Card-based event/announcement layout for quick scanning.
- **Navigation:** Simple links to Home, Events, Create Event, Notifications, Contact. Responsive for desktop/tablet/phone.
- A low-fidelity wireframe will demonstrate placement of navigation, event cards, announcements and contribution info.

## 6. Technical Requirements
- HTML5 structure, CSS for styling and responsive design, JavaScript for interactivity.
- Domain name and web hosting required for public deployment (GitHub Pages used for initial hosting).
- Initial focus: front-end structure and functionality; advanced features added in later stages.
